自由銘柄・自由期間 BB下限ケース分析 v2.2.0

v2.1.0の1ケース分析をすべて残し、複数銘柄・複数Day0を比較台帳へ蓄積する機能を追加。

使い方
1. これまで通り1ケースを分析。
2. 「今回のケースを比較台帳に追加」を押す。
3. 別の銘柄/Day0を分析して追加。
4. セクション11～14で比較。
5. 「比較台帳CSVを保存」でCSVを保存。
6. 次回起動時は「以前保存したケース台帳CSVを読み込む」で継続。

重要
- Streamlitの一時メモリだけに依存せず、継続利用時は台帳CSVを保存してください。
- 20営業日比較は同じ評価期間だけを集計します。
- 未決着は件数に残し、Net R統計には混ぜません。
- 比較結果からStop方式を自動採用しません。
- v5.3凍結AIとは完全に別です。
