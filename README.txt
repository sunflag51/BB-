【自由銘柄・自由期間 BB下限ケース分析 v2.4】

この版では、従来の表形式を残したまま、初心者向けのグラフィック表示を追加しました。

主な追加点
1. まず最初に見るダッシュボード
   - シグナル別の要点をカード形式で表示
   - 購入株数、想定損失、最良Stop方式を先に確認できます

2. 1ケース分析のグラフ強化
   - 価格チャート（Close / BB Lower / BB Middle / BB Upper）
   - Stop幅（1R%）比較グラフ
   - 1RのATR倍率比較グラフ
   - 20営業日 Net R比較グラフ

3. 蓄積ケース比較のグラフ強化
   - 銘柄ごとのケース数
   - 全銘柄参考集計のNet平均R
   - 銘柄別Net平均R
   - NetR計算可能率
   - 価格構造1RのATR比帯の分布

使い方のおすすめ順
① 1ケース分析を実行
② ダッシュボードで要点を確認
③ 必要なら詳細表を見る
④ 「今回のケースを比較台帳へ追加」
⑤ 複数ケースをためたら、蓄積ケースのグラフ比較を見る

起動方法
streamlit run main.py
