自由銘柄・自由期間 BB下限ケース分析 v2.5.0

main.py、case_study_core.py、requirements.txtを同じフォルダに配置してください。
起動: streamlit run main.py

波のチャートを分析開始日～分析終了日の全期間に変更。Day0は黒い破線です。
50日線（紫）・200日線（オレンジ）、陽線（赤）・陰線（緑）を維持。
転換点は前後の確認本数で判定し、末尾の未確定部分は転換点を表示しません。
全期間の事後表示なので、基準日前の点も基準日以降に確定する場合があります。
波の一覧には確定日を表示します。波は売買・Stop計算に使用しません。
旧比較台帳CSVは引き続き使用可能。為替の自動取得など既存機能も維持。

追加: market_view.pyを同じフォルダへ配置してください。米国4指数の100基準比較と騰落率平均、米国11セクターETFの強弱・主導カラー帯・順位を表示。市場スコアは4指数の単純平均で、重複構成銘柄を考慮した独立指標ではありません。主導は過去5/20/60営業日騰落率首位と定義。日本市場のセクター分類ではありません。為替換算なしの米ドル建てETF比較です。10分キャッシュ、再取得ボタンあり。欠損を埋めず、全11セクターが揃う日に主導を判定します。
