自由銘柄・自由期間 BB下限ケース分析 v2.7.0

ファイルをすべて同じフォルダへ配置してください。
 main.py / case_study_core.py / market_view.py / ai_analysis.py / ai_view.py / requirements.txt
ローカル: pip install -r requirements.txt → streamlit run main.py
Streamlit Cloud: 上記ファイルをリポジトリへ配置し、main.pyを指定します。

使い方:
1. 銘柄・基準日・分析期間を入力して完全分析。
2. 市場欄で所属セクターを確認・変更。
3. AI特徴分析欄で判定営業日数（初期5）、上昇下降の幅（初期±2%）、波確認数を指定。
4. この条件でAI特徴分析を実行。
5. 別期間検証と多数派基準の比較を確認。
6. 説明日を選び、決定木が実際に使った条件と同じ条件の学習例を確認。

株価は分割・配当調整済み。今日の未完成日足は除外します。
予測対象は当日終値からh営業日後の終値の騰落率。末尾h日は結果未確定。
特徴計算には開始日前の650暦日を取得しますが、学習・検証対象は選択期間内だけです。
学習約75%・検証約25%、検証開始日に結果未確定の学習データは日付で除外。
決定木は最大3段、葉の学習例は10例以上（学習日数によってさらに増加）。
学習120日・検証40日以上、最低2分類で各10例以上必要。不足時は理由と集計だけ表示。
波は確認が済んだ日から特徴へ反映し、全期間の波線をそのままAIへ渡しません。
市場・セクターは銘柄の判定日より前の米国取引日の値だけ使用（最大5暦日前）。
市場の欠損が多い特徴は学習候補期間のカバレッジで除外し、画面に明記。
所属セクターは現在の企業分類を使用し、過去の分類変更を再現しません。
分類の割合は同じ条件の過去学習例の比率で、校正済みの将来確率ではありません。
重要度は固定した検証期間のPermutation Importance。設定を繰り返し変更すると検証への適合が起こります。
上昇・下降の原因を証明するものではなく、Stop/売買利益を予測しません。
株価・為替・市場・セクター・旧比較台帳の機能を維持します。

v2.6.1: 自動分類の取得失敗と選択状態固定を修正。企業情報のsectorKey/sector/sectorDispを表記統一して照合し、失敗時は銘柄コードが一致する検索結果を補助に使用。成功情報は1時間、失敗は最大60秒の保存。再取得ボタンはキャッシュを消して自動選択へ戻します。手動指定は通常の画面更新で維持。再取得にも失敗する場合は理由を画面に表示し、分類を推測で割り当てません。

 v2.6.2: AI結果をコピーして相談する欄を追加。テキスト枠右上のコピーアイコンで、現在の選択日・設定・理由・特徴量・検証成績・分類内訳・重要度をまとめてコピーできます。同じ内容のテキスト保存も可能。

v2.6.3: 正解率の横に上昇予測の的中率、下降を捉えた割合、予測の偏り（最多分類と割合）を追加。対象日0は算出不可。分類ごとの内訳と未予測分類の注意を表示。相談用コピーとテキスト保存に同じ指標を追加。

v2.6.4: 検証日ごとの判断条件番号を追加。全学習条件ごとの予測分類、学習日数、検証日数、正解日数、検証的中率、実際の3分類内訳と分岐条件を集計。同じ条件に集中した場合と、複数条件が同じ分類を答える場合を区別。選択日の条件に★。相談用コピーとCSVにも追加。AIの学習・予測方法は従来と同じで、今回の更新は理由の診断機能です。更新後にAI特徴分析を再実行してください。

v2.7.0: ai_walkforward.py と ai_walkforward_view.py を追加。ai_view.pyと同じフォルダに置いてください。AI分析実行後「時期をずらしたAI検証」欄で4通りの時系列比較を実行。学習126日（初期）/252日、検証42日（初期）/21日/63日。各期間の開始前に結果確定した直近日数のみ学習、最大3段の決定木を市場特徴・分類補正の4通りで比較。市場特徴は各学習期間の95%充足率で採否を決め、欠損は学習中央値補完。学習不足・市場不足は4通りとも期間を除外。全体成績、期間別グラフ、境界監査、全予測CSV、相談用コピーレポートを追加。上部の固定モデルの分類は変更しません。比較で選んだ方法には別の未使用期間の検証が必要です。
