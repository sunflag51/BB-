自由銘柄・自由期間 BB下限ケース分析 v2.4.8

main.py / case_study_core.py / requirements.txt を同じフォルダへ配置してください。
Streamlit Community Cloudでは3ファイルをリポジトリへ入れ、main.pyを指定します。
ローカル起動:
  pip install -r requirements.txt
  streamlit run main.py

完全分析を押した後、基準日前のローソク足と波が表示されます。
ローソク足は赤が陽線、緑が陰線。波の目印は赤が高値、緑が安値、黄色は転換点を結ぶ波です。
前後確認日数は初期値3。大きくすると細かな波が減ります。
BB表示切替、ドラッグ移動、スクロール拡大縮小、ツールバーのリセットが使えます。
実際のTradingView埋込ではなくPlotlyによるTradingView風表示です。

基準日は既存のDay0定義に従い、非取引日は次営業日に移動します。
波の計算はDay0より前だけを使い、確定日もDay0より前に限定します。
末尾の前後確認日数分は未確定のため転換点にしません。
同種転換点はより極端な点を残します。同日に高値・安値の両方に該当する足は除外します。
分析開始日より前の波は表示・検出しません。
Stop方式、資金管理、台帳CSVの列と計算方法はv2.4のままです。
旧台帳CSVをそのまま読み込めます。

変更点: 両価格チャートを白背景・黒文字に変更。基準日前後チャートはローソク足とBBバンド、Day0の黒破線で表示。

v2.4.8: 比較本数を比較組み合わせ数に変更し、内訳を表示。ダッシュボードでUSD/JPYレートを入力すると想定損失を円・ドルで併記します。表示用レートは株数・Stopの計算には使用しません。

v2.4.8: シグナル未成立でも基準日価格・BB状態と2シグナルの判定理由を表示。チャートを維持します。

v2.4.8: グラフ2～4を全幅の横棒に変更。2行の名称と棒の数値、一覧表を表示。未確定結果はゼロに置き換えません。

v2.4.8: 両ローソク足チャートに終値の50・200営業日単純移動平均線を追加。紫=50日、オレンジ=200日。陽線は赤、陰線は緑。過去データが不足する移動平均は非表示になります。

v2.4.8: グラフ5～9も全幅の横棒に変更。銘柄・シグナル・方式を左側に改行表示し、数値一覧を追加。グラフ9は4帯の横向きグループ棒を表示。

v2.4.8: 想定損失の円・ドル表示用にYahoo FinanceのJPY=Xを自動取得。直近5日の1時間足の有効な最終終値を使用し、時刻を表示。5分キャッシュ、再取得、手入力を選択可能。取得失敗時は架空のレートで代用しません。資金管理の換算レートは従来通り手入力です。
