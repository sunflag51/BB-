使い方:
1. 銘柄・基準日・分析期間を入力して完全分析。
2. 市場欄で所属セクターを確認・変更。
3. AI特徴分析欄で判定営業日数（初期5）、上昇下降の幅（初期±2%）、波確認数を指定。
4. この条件でAI特徴分析を実行。
5. 別期間検証と多数派基準の比較を確認。
6. 説明日を選び、決定木が実際に使った条件と同じ条件の学習例を確認。

株価は分割・配当調整済み。今日の未完成日足は除外します。
予測対象は当日終値からh営業日後の終値の騰落率。末尾h日は結果未確定。
特徴計算には開始日前の650暦日を取得しますが、学習・検証対象は選択期間内だけです。
学習約75%・検証約25%、検証開始日に結果未確定の学習データは日付で除外。
決定木は最大3段、葉の学習例は10例以上（学習日数によってさらに増加）。
学習120日・検証40日以上、最低2分類で各10例以上必要。不足時は理由と集計だけ表示。
波は確認が済んだ日から特徴へ反映し、全期間の波線をそのままAIへ渡しません。
市場・セクターは銘柄の判定日より前の米国取引日の値だけ使用（最大5暦日前）。
市場の欠損が多い特徴は学習候補期間のカバレッジで除外し、画面に明記。
所属セクターは現在の企業分類を使用し、過去の分類変更を再現しません。
分類の割合は同じ条件の過去学習例の比率で、校正済みの将来確率ではありません。
重要度は固定した検証期間のPermutation Importance。設定を繰り返し変更すると検証への適合が起こります。
上昇・下降の原因を証明するものではなく、Stop/売買利益を予測しません。
株価・為替・市場・セクター・旧比較台帳の機能を維持します。
