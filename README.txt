自由銘柄・自由期間 BB下限ケース分析 v2.3.0

v2.2.0の1ケース分析・複数ケース台帳・CSV保存/復元をすべて維持し、
蓄積したケースを研究しやすくする比較診断を追加した版です。

追加した研究診断
15 20営業日・Net R計算可能率監査
16 20営業日・銘柄等重み参考集計
17 20営業日・価格構造Stopとの差（同一ケース）
18 価格構造1R・ATR倍率分布
19 価格構造1R・ATR比ケース明細

v2.3のポイント
- 16番は、各銘柄内の平均Net Rを先に計算し、銘柄を同じ1票として平均します。
  ケース数の多い銘柄が全体平均を強く支配する影響を確認するための参考集計です。
- 17番は、同じCase_ID・同じシグナル・同じ20営業日評価の中で、
  ATR StopのNet Rから価格構造StopのNet Rを引いて比較します。
- 18・19番は価格構造1Rの幅を%とATR換算で確認します。
  <0.25ATR / 0.25～<0.50ATR / 0.50～<1.00ATR / >=1.00ATR は診断区分であり、売買フィルターではありません。
- 14番の評価期間表示を 5営業日 → 10営業日 → 20営業日 → 設定終了日まで の順にしました。
- 同じCase_IDを再追加した場合は、古いそのケース全体を新しい結果で置き換えるようにしました。

互換性
- v2.2で保存した bb_case_ledger_v2_2.csv を、そのままv2.3へ読み込めます。
- v2.3の保存ファイル名は bb_case_ledger_v2_3.csv です。

重要
- 20営業日比較は同じ評価期間だけを集計します。
- 未決着・同日順序不明などNet Rが確定しない行は、件数には残しNet R統計には混ぜません。
- 銘柄等重み集計も、Stop方式の自動採用を意味しません。
- 価格構造1RのATR比区分も、自動的なStop変更・ケース除外を行いません。
- v5.3凍結AIとは完全に別のケーススタディです。
