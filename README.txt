株価ケース分析 v3.1.0：保存・呼び出しを簡単にしました

普段使う操作は3つです。
1. 銘柄・日付・資金などを入力し、入力欄の最後で名前を付けて「分析セットに保存」。
2. 上部の一覧から名前を選び「このセットを呼び出す」。その後、分析ボタンを押します。
3. 「全部まとめてバックアップを保存」で stock_analysis_backup.json を端末に保存。

分析セットには銘柄・会社名・基準日・開始日・終了日・資金通貨・株価通貨・総資金・予算・
許容損失率・為替方式・手入力為替・ATR期間/倍率・取引コスト・波確認本数を保存します。
自動ドル円の古い価格を固定保存せず、呼び出した後に最新取得可能なレートを取得します。

再起動・別端末では「バックアップ・以前のCSVを読み込む」でJSONを1回読み込めば復元できます。
設定を追加・変更・削除した後は最新のバックアップをダウンロードしてください。
画面の一覧はブラウザーセッション内の保存です。閉じても必ず残る永続保存ではありません。
共有サーバーのファイルに全ユーザーの資金設定を自動で書き込む方式は使っていません。
株価・分析結果は保存セットを呼び出した後に再取得・再計算します。

バックアップには分析セット・銘柄一覧・以前の期間設定・資金設定・比較台帳をまとめます。
同じ内容を再読込しても分析セットは重複しません。異なる内容の同名セットは別名で追加します。
入力している設定は「分析セットに保存」を押してからバックアップしてください。

以前のCSVは同じアップロード欄で自動判別します。
analysis_profiles.csv：分析セットへ変換。以前のCSVにない資金値は現在の画面の値を組み合わせます。
saved_tickers.csv：銘柄一覧へ追加。
capital_profiles.csv：以前の資金設定一覧へ追加（詳細管理の資金設定から呼び出します）。
bb_case_ledger_v2_4.csv：比較台帳へ追加。同じCase_IDは最新の読込結果に置き換えます。
以前の個別管理は「以前の個別CSV管理・比較台帳を開く」で利用できます。
読込ファイルが不正な場合、既存の一覧を変更しません。

今回の検証：JSON保存/復元、同名重複、同名競合の別名化、銘柄・日付・資金の反映、
以前の分析条件CSV変換、不正ファイルで既存データが変わらないこと、構文を確認しました。
Streamlit実画面とネットワークによる株価取得はこの作成環境で未確認です。

------------------------------------------
株価ケース分析 v3.0.0

今回の変更
未来の上昇・下降を分類するAI画面を終了し、過去に完了した波の結果分析へ切り替えました。
全期間の波のチャートの直下に、同じ転換点による分析を表示します。

使い方
1. 銘柄、分析期間、基準日を選び、分析を実行します。
2. 全期間の波のチャートで「転換点の前後に確認する営業日数」を設定します。
3. 直下の過去の波の結果分析で、安値→高値と高値→安値の値幅・期間を比較します。
4. 波番号を選んで、開始日の移動平均線、BB、出来高、ATR、直前の騰落率を確認します。
5. 条件の該当割合、方向別の中央値、AIによる条件の組合せ整理を確認します。
6. CSVを保存するか、相談用レポートを開いて右上のコピーアイコンからコピーできます。
銘柄ごとの分析です。銘柄や期間を変更して比較できます。

AIの役割
同方向の完了波12件以上で、開始条件とその後の絶対値幅の関連を浅い決定木で整理します。
入力は開始日の数値のみ。終了価格や保有日数を条件に使いません。
全件を探索用に整理します。将来の売買予測・確率・検証正解率は表示しません。
条件グループには件数、値幅の中央値・平均・最小・最大、該当波番号を表示します。
欠損のある波はモデルから除外し、確認できない条件を0に置き換えません。
50日線・200日線などは表示開始日前の取得データも使って計算します。
市場・セクター画面は引き続き表示しますが、今回の波の条件モデルには未組込みです。

読み方の注意
転換点は前後の足で事後確定します。同種の転換点は後からより極端な点に置換されます。
開始条件は転換点当日の終値時点の状態で、その日に転換点を知れたという意味ではありません。
開始・終了の確定日を波の一覧に表示します。未完了の最終区間は集計しません。
安値と高値の間の値幅は、実際に得られる売買利益ではありません。
条件該当割合は「その方向の波のうち条件が揃った割合」です。
「条件が揃った日に上昇する確率」とは分母が異なります。
関連は原因や必要条件・十分条件の証明ではありません。別期間でも確認してください。
波の確認本数を変えると転換点と分析結果も変わります。端の未確定の足は対象外です。

継続機能
ケース分析、資金管理とドル円取得、銘柄リスト、期間・資金設定のCSV保存と復元、
全期間ローソク足・50/200日線・BB・出来高、米国/日本市場の自動切替を継続しています。
以前削除した仮説研究室は追加していません。

設置
ZIPを展開し、収録したファイル一式を既存のアプリのファイルと置き換えてください。
Streamlit Cloudの起動ファイルは main.py、依存関係は requirements.txt です。
ローカル起動: pip install -r requirements.txt
              streamlit run main.py
保存したCSVは手元に残して、必要に応じてアップロードして復元してください。
